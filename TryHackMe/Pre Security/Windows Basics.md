# Topics Covered

## ✅ Windows Desktop

**What I Learned**

* The desktop is the primary workspace where files, folders, and shortcuts are stored.
* It provides quick access to commonly used applications and documents.

---

## ✅ Taskbar

**What I Learned**

* The taskbar provides quick access to applications, system tools, notifications, and pinned programs.
* It also displays running applications and system status.

---

## ✅ Start Menu

**What I Learned**

* The Start Menu is the central hub for launching applications, accessing settings, and managing power options.
* It allows users to quickly locate installed software.

---

## ✅ Windows Search

**What I Learned**

* Windows Search allows users to quickly locate applications, files, folders, and system settings.
* It improves productivity by reducing navigation time.

---

## ✅ File Explorer

**What I Learned**

* File Explorer is used to browse, organize, copy, move, rename, and delete files and folders.
* It is the primary file management tool in Windows.

---

## ✅ Windows Update

**What I Learned**

* Windows Update keeps the operating system secure and up to date.
* It installs feature updates, bug fixes, and security patches released by Microsoft.

---

## ✅ Microsoft Store

**What I Learned**

* Microsoft Store provides trusted applications that can be safely downloaded and installed.
* It helps users manage application updates.

---

## ✅ Windows Settings

**What I Learned**

* Windows Settings provides centralized access to device, network, personalization, privacy, and security settings.
* It is the modern configuration interface for Windows.

---

## ✅ Control Panel

**What I Learned**

* Control Panel contains legacy system configuration tools.
* It allows advanced management of hardware, software, user accounts, and networking.

---

## ✅ Task Manager

**What I Learned**

* Task Manager monitors running processes, system performance, startup applications, and resource usage.
* It can be used to troubleshoot applications and identify high CPU or memory usage.

---

## ✅ Windows Security

**What I Learned**

* Windows Security acts as the central dashboard for Windows' built-in security features.
* It provides access to antivirus protection, firewall settings, account protection, and device security.

---

## ✅ Windows Defender Firewall

**What I Learned**

* Windows Defender Firewall monitors incoming and outgoing network traffic.
* It helps protect the system from unauthorized network access and malicious connections.

## Key Terminology

| Term                          | Description                                                                              |
| ----------------------------- | ---------------------------------------------------------------------------------------- |
| **Desktop**                   | The main workspace where files, folders, and shortcuts are stored.                       |
| **Taskbar**                   | A control strip providing quick access to applications, notifications, and system tools. |
| **Start Menu**                | The primary location for launching applications, accessing settings, and power options.  |
| **Windows Search**            | A feature used to quickly locate files, applications, and settings.                      |
| **File Explorer**             | Windows' built-in file management application.                                           |
| **Windows Update**            | The service responsible for installing Windows updates and security patches.             |
| **Microsoft Store**           | The official platform for downloading trusted Windows applications.                      |
| **Windows Settings**          | The primary interface for configuring Windows devices.                                   |
| **Control Panel**             | A legacy interface for advanced system configuration.                                    |
| **Task Manager**              | A tool used to monitor processes, performance, and system resources.                     |
| **Windows Security**          | The dashboard for managing Windows' built-in security features.                          |
| **Windows Defender Firewall** | A firewall that protects the computer by filtering network traffic.                      |
